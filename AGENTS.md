# Todoaldía Documentation

The documentation source is HTML/CSS.
PDF files are generated artifacts and must never be edited directly.

## Visual rules

- Landscape A4.
- Use Plus Jakarta Sans.
- Background must match Todoaldía warm background.
- Orange is the primary emphasis color.
- Important cards use subtle blurred shadows.
- Maintain safe spacing between text and screenshots.
- Never overlap text and images.
- Figure captions always appear below screenshots.
- Use semantic bold for important actions.
- Never manually position consecutive fragments of the same sentence.
- Prefer normal document flow, grid and flexbox.

## Content rules

- Use "tu negocio", "el negocio" or "el negocio de ejemplo".
- Do not use visible difficulty levels.
- Explain the interface before showing the practical example.
- Do not document behavior that has not been confirmed.
