Estas relaciones son importantes porque permitirán que el lector comprenda que los módulos no funcionan como aplicaciones completamente aisladas:
Pedidos → Preparación: el pedido recibido continúa hacia el área encargada de prepararlo. La web confirma este flujo por estados. 
Caja → Ventas: una operación registrada pasa a formar parte de la actividad comercial consultable.
Productos → Caja / Tienda: el catálogo alimenta los espacios donde se ofrecen los productos.
Productos → Inventario: el control de stock mantiene las existencias relacionadas con los productos.
Gastos → Inventario: los productos incorporados mediante ¿Qué compraste? entran al inventario al guardar.
Tienda online → Zonas de reparto: Delivery local utiliza las áreas y tarifas definidas en Zonas de reparto.
Canales de venta → WhatsApp Business: uno controla la disponibilidad del canal y el otro sus datos.
Pedidos → Delivery: cuando corresponde despacho, el pedido continúa hacia el flujo de reparto.
Sitio web → Pedidos: la web oficial confirma que los pedidos generados en el sitio llegan directamente al panel.
